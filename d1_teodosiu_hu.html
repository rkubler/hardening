D1 · Microstructure-based and distortional models

Teodosiu–Hu model (1995)

A microstructure-based model for sheet steels. Besides the back stress, it follows the persistent dislocation structures (dislocation walls and cells) through a tensor S and their polarity P. It describes what happens when the strain path changes: transient softening and workhardening stagnation after a reversal, and cross hardening after an orthogonal change. The loading is applied to a thin-walled tube in tension–torsion.

Constitutive equations

J(σ − X) = Y,   Y = Y0 + R + f |S|      dR = CR (Rsat − R) dp      dX = CX (Xsat N − X) dp
Xsat = X0 + (1 − f) |S| √(r + (1 − r) βS²),   βS = SD/|S|      SD = N : S : N,   SL = S − SD N ⊗ N
dSD = CSD [ g (Ssat − SD) − h SD ] dp      dSL = −CSL (|SL|/Ssat)nL SL dp      dP = CP (N − P) dp
h = ½ (1 − X : N / Xsat)      g = 1 − cP |SD/Ssat − P : N| if P : N ≥ 0,   g = (1 + P : N)nP (1 − cP SD/Ssat) otherwise,   cP = CP/(CSD + CP)
  • N is the direction of the plastic strain rate. X is a back stress, describing the short-range effects (pile-ups against the walls); R is a small isotropic hardening.
  • S (a fourth-order tensor) is the strength of the persistent dislocation structures. It is split into a directional part SD, linked to the structures that are active for the current direction N, and a latent part SL, linked to the structures formed during earlier strain paths. A fraction f of |S| adds to the yield stress, the rest increases the saturation of the back stress.
  • P is the polarity of the dislocation structures: it remembers the direction in which they were built. After a reversal, P : N < 0 and g ≈ 0, so SD stops growing until P has turned to the new direction (rate CP).
  • h makes SD decrease just after a reversal, when the back stress opposes the new flow (X : N = −Xsat, h = 1): the old walls dissolve.
  • SL decays at the rate CSL once the path has changed: the old structures are slowly destroyed.

What to look for

Reverse loading. In the first plot, the reverse curve starts well below the monotonic one (Bauschinger effect from X). It then stays nearly flat for a few percent: the walls built in tension dissolve (h) and new ones cannot grow yet (g ≈ 0 while P still points to the old direction). This plateau is the workhardening stagnation. Hardening restarts once P has turned; the gap that remains is the permanent softening.

Orthogonal change (tension, then shear). At the change, the structures built in tension become latent (SD → 0, |SL| = |S|). New structures grow in the shear direction while the latent ones decay slowly, so |S| rises above its monotonic value and the curve passes above the monotonic one: cross hardening. The overshoot is larger when CSL is small and f is close to 1. Just after the change, the back stress still points in the tension direction, which lowers the equivalent re-yielding stress.

Yield surface display. The surface stays a von Mises circle (no distortion); it translates with X and grows or shrinks with Y. Compare with D2 and D3, where the shape itself changes.

The tension–torsion plane holds two independent strain directions, so S is represented here by a 2 × 2 symmetric matrix in that plane, which is enough for the two path changes shown. The form of g above is the one used in the later implementations of the model for sheet steels; check the original papers for the exact form used in an identification. Parameters are illustrative, chosen to make each effect visible.
