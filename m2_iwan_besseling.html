M2 · Multisurface and two-surface models

Iwan (1967) and Besseling (1958) overlay model

The material is a set of elastic–perfectly plastic elements loaded in parallel, all with the same strain. Each element yields at its own stress, so the stress–strain curve is piecewise linear. Watch the elements yield one after the other, the loops follow Masing's rule and the material remember the past loading after an inner loop.

Constitutive equations

σ = Σk wk σk      σk = E (ε − εpk),   |σk| ≤ σy,k      Σk wk = 1
  • Elements (Besseling's sub-volumes, Iwan's spring–slider units): each one has the same Young's modulus E, a yield stress σy,k and a volume fraction wk. All elements see the same total strain ε.
  • Yielding: element k is elastic while |σk| < σy,k and then carries a constant stress ±σy,k (perfect plasticity).
  • Tangent modulus: when elements 1 to j have yielded, the slope is E (1 − w1 − … − wj). The stress is bounded by Σ wk σy,k.

Iwan (1967) described the same idea in two equivalent ways: springs and sliders in parallel, or nested yield surfaces as in Mróz's model. Besseling (1958) wrote it as a material made of sub-volumes with different yield stresses. In uniaxial loading the overlay model and the Mróz model give exactly the same curves when they share the same monotonic curve: the element yield stresses play the role of the surface sizes.

What to look for

Monotonic test. One kink each time an element yields. The dashed line is the limit stress Σ wk σy,k.

Strain cycles. On reversal every element unloads elastically, so reverse yielding starts after a stress drop of 2σy,1: the Bauschinger effect comes from the residual stresses between elements, not from a back stress variable. The dashed curve is Masing's prediction σ = σmin + 2 f((ε − εmin)/2), where f is the monotonic curve: it lies on top of the loop, because the overlay model obeys Masing's rule exactly. With a mean strain, the mean stress is set during the first cycle and then stays constant: there is no progressive relaxation. It drops to zero only if the amplitude is large enough to make every element yield in both directions.

Memory path. After an inner loop, the curve goes back exactly to the point where the loop started and then continues as if the loop had not happened (the memory rule used in rainflow counting).

Stress cycles. Once the first cycle is done, the loop closes and the strain at σmax stays constant: the model cannot predict ratcheting or mean stress relaxation, and it has no cyclic hardening or softening. These limits led to the two-surface and nonlinear kinematic models (M3–M5, A–E).

The model here is uniaxial. In multiaxial loading the overlay model also gives a reasonable response under non-proportional paths, because each element has its own von Mises surface.
