E3 · Models designed for ratcheting

Bari–Hassan (2000, 2002)

A three-term Chaboche model in which every back stress uses the Delobelle recall, with an optional threshold on the last term. δ′ controls multiaxial ratcheting, the threshold controls uniaxial ratcheting. Each run compares it with the plain Chaboche model.

last term with threshold: the recall of X3 is multiplied by ⟨J(X3) − X̄l⟩ / J(X3)
  • The three terms describe the loop shape, as in Chaboche (B).
  • δ′ is the Delobelle weight (E2): it acts only when the back stress is not aligned with the flow, i.e. under multiaxial or non-proportional loading.
  • X̄l is the Chaboche threshold (C): it acts in uniaxial loading too. X̄l = 0 gives the pure Chaboche–Delobelle combination.

What to look for

Axial stress + cyclic shear. δ′ < 1 reduces axial ratcheting compared with Chaboche. Bari and Hassan tune δ′ on a biaxial test and the other parameters on uniaxial tests.

Uniaxial stress cycles. With X̄l = 0 the two curves coincide, because δ′ has no effect in uniaxial loading. Set a threshold (for example 150 MPa, below C3/γ3) to reduce uniaxial ratcheting as well.
